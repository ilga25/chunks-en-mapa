# Chunks en Mapa

Convierte un rectángulo de coordenadas X/Z en chunks de Minecraft, cuenta los intersectados y consulta sus límites, incluidas las coordenadas negativas.

GitHub Pages: main, raiz. https://ilga25.github.io/chunks-en-mapa/

Fuentes estaticas sin dependencias. Pruebas del motor: work/ten-tools/check.cjs. Guia propia, privacidad y sitemap incluidos. Sin garantia de trafico, indexacion, aprobacion publicitaria o ingresos.
